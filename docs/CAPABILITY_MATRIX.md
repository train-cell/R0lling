# Capability map

Updated: 2026-10-13. Current authority: IMPLEMENTATION_STATUS.md and the source files below. “Implemented” refers to a source path; Apple build/runtime validation remains pending.

**Obsidian Dataview (2026-10-13):** Existing bridge frontmatter (date, type, app, tags) is documented with a Dataview query and placeholder-only schema template in [OBSIDIAN_DATAVIEW.md](OBSIDIAN_DATAVIEW.md). No example journal content is fabricated; actual plugin rendering remains unverified.

**Meta DAT (2026-10-13):** The iOS package declares DAT 1.0.1 and the app contains SDK initialization, callback handling, and Developer Mode plist scaffolding. Source now includes user-triggered registration/session lifecycle, explicit camera-permission confirmation, a retained camera publisher, a bounded loss-reporting frame queue, and raw-to-H.264 Annex-B encoding; none has been Apple-built or device-verified. The encoder expects 504×896 medium frames and stops on resolution changes. The adapter remains simulation-first and `MetaDATStreamBridge.einaiLiveYlopoiimeno` remains false; photo, audio, and IMU remain unwired, and SDK battery/name mapping is unverified. The SDK exposes experimental camera PCM and `MWDATMotion` APIs, but R0lling does not use either sensor surface; the `MWDATMotion` product is not linked, Motion requires Developer Center capability approval, and experimental capabilities are not production-publishable. See [SETUP_META.md](SETUP_META.md).
