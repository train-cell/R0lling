# R0lling — Οδηγός Ρύθμισης AI & Hermes Agent (SETUP_AI_HERMES)

**Έργο:** `R0lling`  
**Επιλογές AI:** Hermes Agent (Home PC) & Direct AI API (Cloud)  
**Ημερομηνία:** 6 Οκτωβρίου 2026  

---

## 1. Επιλογή Α — Hermes Agent στο Home PC (Jarvis Mode)

Ο **Hermes Agent** εκτελείται στον προσωπικό υπολογιστή του σπιτιού και λειτουργεί ως ιδιωτικός βοηθός.

### 1.1 Εκκίνηση Gateway στον Υπολογιστή (PC)
```bash
# Εγκατάσταση και εκκίνηση Hermes API Gateway
hermes gateway start --host 0.0.0.0 --port 8080 --api-key "YOUR_SECRET_HERMES_TOKEN"
```

### 1.2 Ασφαλής Σύνδεση από το iPhone
- **Εντός σπιτιού (Wi-Fi):**
  Χρησιμοποιήστε την τοπική IP του υπολογιστή σας:
  `http://192.168.1.50:8080/v1`
- **Εκτός σπιτιού (Κινητό δίκτυο / 5G):**
  **ΠΟΤΕ** μην ανοίγετε θύρες (port forward) στο router σας στο δημόσιο διαδίκτυο!
  Χρησιμοποιήστε ένα ασφαλές VPN, όπως το **Tailscale** ή το **WireGuard**:
  `http://100.x.y.z:8080/v1` (Tailscale MagicDNS / IP).

### 1.3 Ρύθμιση στο R0lling
1. Ανοίξτε το R0lling -> `Ρυθμίσεις` -> `Πάροχος Τεχνητής Νοημοσύνης (AI)`.
2. Επιλέξτε **`Hermes (Home PC)`**.
3. Εισάγετε το URL: `http://192.168.1.50:8080/v1` (ή το Tailscale IP).
4. Εισάγετε το Bearer Token: `YOUR_SECRET_HERMES_TOKEN`.
5. Πατήστε `Αποθήκευση Ρυθμίσεων AI`.

---

## 2. Επιλογή Β — Άμεσο AI API (Direct Cloud API)

Αν το Home PC είναι κλειστό ή θέλετε μια απλούστερη cloud διαδρομή:

1. Ανοίξτε το R0lling -> `Ρυθμίσεις` -> `Πάροχος Τεχνητής Νοημοσύνης (AI)`.
2. Επιλέξτε **`Direct AI API`**.
3. **Base URL:** `https://api.openai.com/v1` (ή συμβατό endpoint).
4. **Model Name:** `gpt-4o-mini` (ή `gpt-4o` για υψηλότερη ακρίβεια vision).
5. **API Key:** Εισάγετε το κλειδί σας (π.χ. `sk-...`).
6. Πατήστε `Αποθήκευση Ρυθμίσεων AI`.

---

## 3. Προστασία Προσωπικών Δεδομένων (Context Scrubbing)

- **Χωρίς μαζική αποστολή:** Το R0lling στέλνει στο AI **μόνο** τις σχετικές καταχωρήσεις της ημέρας και τη μνήμη του Agent.
- **Vision On-Demand:** Η κάμερα των γυαλιών δεν στέλνει συνεχή ροή βίντεο στο cloud. Αποστέλλεται **ένα μόνο καρέ (snapshot)** αποκλειστικά όταν πατήσετε το «Τι βλέπω;» ή στο παιχνίδι παρατήρησης.
- **Keychain Storage:** Τα κλειδιά API δεν αποθηκεύονται σε αρχεία logs ούτε εξάγονται στα backups.
